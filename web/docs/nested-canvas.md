# 嵌套画布：从总架构一层层进到代码逻辑

架构图上的一个节点可以「打开」一张子画布：总架构 › 后端 › 订单模块 › 下单流程。每一层都是一张普通画布（`.agora/canvases/<id>.excalidraw`，有自己的评论、分享、会话关联），只是被父节点指着。

实现：`web/src/nested/`（`graph.ts` 纯函数：父子索引、面包屑、代码路径汇总、过时判断、写链接；`store.ts` 所有画布的场景与导航动作；`up.ts` 返回上一级的快捷键与一次性提示；`enter.ts` 进入选中节点的快捷键（⇧↵）和进入标记的点击区；`NestedLayer.tsx` 进入标记、面包屑、「子图」菜单；`writeChild.ts` 写链接；`zoom.ts` 缩放进出与飞行的纯数学：父子镜头映射、阈值、缓动，`zoom.test.ts` 测它；`zoomNav.ts` 缩放切换、点击飞进飞出、到达时的替身；`ZoomLayer.tsx` + `zoom.css` 画在画布图层上的子图缩略图和遮罩），`web/src/buildreplay/scenePicture.ts`（子图缩略图：Excalidraw 的 SVG 导出，按子图版本缓存，和回放用同一份），`web/scripts/zoom-capture.ts`（录缩放进出 / 飞行的视频并记下每帧时间和切换时刻），`web/src/canvas/nodes.ts`（什么算一个节点：选区、`--node` 都经过它），`web/src/canvas/NodeBar.tsx`（选中节点旁的操作条），`web/src/app/App.tsx`（在原 tab 里切换层级、地址栏、前进后退），`web/src/session/agentBridge.ts` 的 `childFromAgent`；服务端 `server/canvas/nested.py`，`agora canvas child`（`agora_cli/canvas.py` → `/api/agent/canvas/child`），分享网关 `server/canvas/share_gateway.py`。

## 1. 数据：链接只在父节点上

| | |
|---|---|
| 存在哪 | 父节点（方框、椭圆、菱形、frame）的 `customData.childCanvas = "<子画布 id>"`，随父画布存盘、进 git |
| 编组节点 | 素材库图标（一组元素：透明根矩形 + 各层子编组 + 标签）是**一个节点**，链接写在根矩形上——和它的 `codePaths` 同一个元素，也是 `agora canvas read` 列出的节点 id；图标的零件和标签都不带链接。自己编的组选中时也是一个节点：组里已有链接的形状，其次带 `codePaths` 的，再次面积最大的（`canvas/nodes.ts` `groupNode`）；双击进组编辑时组里的形状各算各的 |
| 跟随什么 | 子画布的 **id**。改名、移动文件、换分支都不影响；id 在 `workspace.json` 里对应一个名字 |
| 反向关系 | 不另存。谁是谁的父、面包屑、层级深度，都从所有画布的场景里推出来（`parentIndex`） |
| 一个子图被两个节点指着 | 复制节点会连 `customData` 一起复制。取第一个（画布顺序，再按场景顺序）做面包屑的父；两个节点都能进 |
| 环 | 创建和 `link` 时拒绝（`wouldCycle`）；有人手改文件造出环，推导在环上停下，不会死循环 |

另外，Excalidraw 自带的元素链接（`element.link`）写成 `?canvas=<id>` 或 `#canvas=<id>` 时，点它也在原地进入那张画布（`onLinkOpen` 拦截）。我们自己的入口不用 `link`：Excalidraw 把链接图标画在元素右上角，正好是评论钉的位置。

## 2. 进入与返回

- **进入标记**：有子图的节点右下角一个小胶囊（进入图标，子图及其下层未解决评论数，可能过时时带一个提示色小点）；编组节点按整个图标连同标签的外框算右下角。点它进入：点击区 26×26 px，常驻但安静（半透明，悬停变实），悬停写「进入子图「名」…」。**不再有双击进入**：双击回到 Excalidraw 自己的行为（编辑节点文字、在空白处加文字）。进入子图只有明确的入口：这个标记、面包屑、`?canvas=` 链接、子图入口胶囊（工位视图）、右键菜单里的「进入子图」，以及键盘上选中节点后按 **⇧↵**（`nested/enter.ts` 的 `enterOnKey`，写在「⋯」里的快捷键说明；在文字框里 ⇧↵ 是换行，不接）。
- **原地切换**：进入时子画布替换当前 tab（同一分组、同一位置），父画布被「关闭」——关闭不是删除，它仍在「所有画布」里。子画布已经在别的分组打开时，直接切过去，不动当前 tab。
- **返回上一级**：子画布上方一条栏，最前面是「← 返回 <父画布名>」按钮，后面是面包屑 `总架构 › 后端 API › 订单服务`（父级悬停时像链接，点任意一级原地回去）。快捷键 **⌘↑**（Mac）/ **Ctrl+↑**（其他）；正在输入文字，或恰好选中一个方框 / 椭圆 / 菱形时不接管（那是 Excalidraw 的「按住 Cmd 加方向键画流程图」）。不用 Backspace / Esc（Excalidraw 在用）。第一次进到子图时按钮下面提示一次「在子图里。点左上角返回，或按 ⌘↑」，点「知道了」或用任何方式返回过一次后，这个浏览器不再提示（`localStorage` `agora.nested.backHint`）。顶层画布没有这条栏。
- **离开时先存**：进入 / 返回替换 tab 之前，先把要离开的画布此刻的场景写进场景表、层级索引并存盘（`App.tsx` `go`）。画布视图把场景变化晚一帧才报上来，不这样做的话「新建空白子图」刚写进节点的链接会随视图卸载丢掉（2026-09-28 修过：子画布建出来了，父节点上却没有链接，也就没有面包屑）。
- **地址栏**：`?canvas=<id>` 跟着当前画布走（换 tab 用 replace，进入 / 返回用 push），所以浏览器前进后退就是逐级进出；带 `?canvas=` 打开页面直接到那一层。
- **所有画布**：子画布缩进挂在父画布下面（`canvasTree`）。

### 缩放进出与飞行

层级之间是连续的：放大一个有子图的节点就进到子图里，在子图里缩小到底就回到父画布；点入口时镜头飞过去，而不是一下换掉。

- **镜头映射**（`zoom.ts`）：子图的内容（`pictureBounds`，和缩略图同一个外框）等比缩进节点的内框（四边各留短边的 8%）并居中，即子图坐标 `q` 在父画布上是 `q·s + t`。父画布此刻的镜头（场景 → 页面：`页面 = 场景·k + (x, y)`）乘上这个映射就是子图的镜头（`childSim`），反过来是 `parentSim`。切换时把算好的镜头交给新画布的第一帧（`viewport.ts` `firstView`），所以切换前后同一块内容在屏幕上同一个位置、同样大小；子画布顶上多一条面包屑栏、窗格往下 45 px，按各自窗格在页面上的位置换算，不会跳。
- **缩略图与遮罩**（`ZoomLayer.tsx`）：画在 Excalidraw 的静态画布之上、交互画布（选区、文字编辑框）和面板之下。在节点上 ⌘ / Ctrl + 滚轮（触控板捏合也是这个）或 Safari 的捏合放大时，光标下那个节点「挂上」：节点占窗格的比例（`fill`，宽高取大的那个）从 0.2 到 0.45，节点里淡入子图的缩略图（盖住节点自己的标签）；0.4 到 0.6，节点以外盖上一层画布底色的遮罩，评论钉、进入标记、进度指针、高亮层跟着淡出。手势停下后遮罩在约 140 ms 里退回去（不挡人看父画布），缩小到 0.16 以下摘掉。
- **什么时候进**：放大中 `fill ≥ 0.78`；或者手势停下（260 ms 没有滚轮）时 `fill ≥ 0.6` 且最后一下是放大——画面上已经只剩子图了。**什么时候出**：子图里缩小中，节点在父画布上的 `fill ≤ 0.6`，或已经到 Excalidraw 的最小缩放（10%）还在缩。进和出的阈值不同（0.78 / 0.6），切换后 350 ms 内不再切，所以在阈值附近来回滚不会抖。
- **不和人抢**：切换后人的手势接着在新画布上起作用（新画布的缩放中心按手势位置补一次 `pointermove`，否则 Excalidraw 会以左上角为中心）；新画布一旦拿到给它的镜头，就不再把镜头改回去。正在编辑文字、拖拽 / 缩放 / 旋转元素、画线中、按着鼠标、回放进行中都不切换；子图已经在别的分组打开时也不切（那里直接切过去才对，见上）。
- **到达时的替身**：新画布挂载、读场景、画出第一帧要几帧时间。这几帧里同一张缩略图（子图自己的图，或父画布上节点里的子图）按新镜头盖在原位，等新画布的镜头对上、场景已有元素、再过 3 帧才淡掉；分组的进场淡入和 Excalidraw 的加载提示在这期间不显示（`zoom.css`）。所以切换没有空白帧。
- **点击飞行**（`zoomNav.ts` `flyInto` / `flyUp`）：进入标记、⇧↵、右键「进入子图」先清掉选区，镜头绕「两端在屏幕上同一点」的那个场景点按几何级数放大，飞到「子图按进入时的居中大小正好落在节点里」的位置（480–700 ms，按缩放倍数，三次 ease-in-out），缩略图随进度淡入、遮罩合上，然后原地换成子图——和以前直接进入看到的一样。⌘↑、「← 返回」、面包屑反过来：子图先在 240 ms 里回到整体（若不在），换到父画布，节点里的子图缩回节点、遮罩打开，落到进来之前父画布的镜头（那时节点还小）或父画布整体（560–700 ms）。飞行中按下鼠标、滚轮、按键（修饰键除外）就停在当下，交给人。
- **面包屑跨几级**：逐级飞出——每一级都走一遍「缩回节点」，中间各级 340 ms，最后一级 560–700 ms，所以跨两级约 1.2 s。这样每一步都看得到自己从哪个节点出来，不会一下跳到陌生的位置；代价是慢一点。地址栏只记一次：第一级 push，后面的用 replace，浏览器后退一次就回到出发的那一层。
- **一律瞬间切换的情况**：点击入口时系统开了「减少动态效果」（`prefers-reduced-motion`：不飞，直接 `go`；滚轮缩放进出仍然有，它只跟着人自己的手势走，本身不加动画）；浏览器前进后退、`?canvas=` 打开；回放镜头带着进出子图（它有自己的镜头）；访客分享页（访客的进入标记和面包屑照旧瞬间切换，也没有缩放进出）；子图是空的、或已经在别的分组打开。
- 离开时先存、地址栏、评论数、工位视图的人像、回放的显现层都照旧：缩放和飞行最后都走同一个 `go`（`App.tsx`），只是多带一个到达镜头。

## 3. 建子图

选中一个节点（编组节点整组选中即可），节点旁的**操作条**上并排两个胶囊：「代码路径」和「子图」。操作条贴着节点放（先右、再左、下、上），不压 Excalidraw 的面板、进度指针的标签、评论钉和节点自己的进入标记，尽量不压别的图形；两个胶囊的弹层同一时间只开一个（开一个就关另一个，再点同一个关掉；打开进度指针的弹层也会关掉它），弹层同样避让（`canvas/nodeBarLayout.ts`）。节点没有标签时标题写「未命名节点」，不显示元素 id。「子图」菜单：

| 节点状态 | 菜单 |
|---|---|
| 没有子图 | **让 AI 展开**（发给这块画布的会话 agent，见下）· 新建空白子图（名字取节点标签第一行，建好后直接进入） |
| 有子图，子图是空的 | 进入子图 · **让 AI 画子图** · 断开（子图保留） |
| 有子图 | 进入子图 · 让 AI 更新子图 · 断开（子图保留） |

**让 AI 展开**发给哪个会话：最后聚焦的会话（且属于这棵画布树）；没有就用这棵树上最近活动的已绑定会话；都没有就像评论交接一样让人先选 agent。发出去的是一段明确的步骤（`child create` → 读节点的 `codePaths` 对应的代码 → 在子画布里画下一层 → `link` 更细的代码路径），不是关键词规则：agent 用的仍是 agora skill 的普通能力。第三层可以是代码逻辑或调用流程；要不要做算法动画由 agent 自己决定，没有专门入口。

## 4. `agora canvas child`

```bash
agora canvas child create --parent <画布> --node <节点 id 或完整标签> [--title 名字]
agora canvas child link   --parent <画布> --node <节点> --child <已有画布>
agora canvas child unlink --parent <画布> --node <节点>
agora canvas child list   [--parent <画布>]
```

- `--node`：`agora canvas read` 列出的节点 id；也可以是素材库图标的任一零件或标签元素的 id、编组 id（`lib-…` / `g-…`），或节点的完整标签——都解析到同一个节点（`canvas/nodes.ts` `resolveNode`）。自己编的组里的形状各自是节点，按 id 指哪个就是哪个。
- `create`：节点已经有子图时返回 `exists` 和那张子图（agent 接着画进去），否则新建一张空白画布（不开 tab）并挂上，返回 `created`。都带 `canvas.id`，之后 `read / apply / link --canvas <id>`。
- 挂链接是父画布上的一次可撤销修改，并在会话里记一张卡片（可撤销）。撤销只去掉链接，子画布留下。
- `list` 服务没开也能用（直接读 `.agora/canvases/`）；其余要服务和打开的页面（和 `apply` 一样，退出码 3）。
- `agora canvas read` 的 `nodes[] / frames[]` 有子图时带 `child: {canvasId, name}`；读子画布时 `canvas.parent = {canvasId, name, nodeId, nodeLabel}`、`canvas.path`（面包屑）。

## 5. 进度指针逐层显示

一个节点代表的代码 = 它自己的 `codePaths` ∪ 它子图（及更下层）所有节点的路径（`effectiveLinks`）。所以 agent 改 `server/orders/service.py` 时：

- 总架构上「后端 API」亮（标签里写「子图 · service.py」表示是从子图汇总上来的）；
- 进到「后端 API」，更细的「订单服务」亮；
- 再进一层，调用流程里的 `place(...)` 亮。

仍然是「最具体的 glob 胜出」，子图的路径通常更细，所以不会抢走兄弟节点的文件。多会话时每层都是一会话一个指针，见 [多 Agent](multi-agent.md)。

## 6. 子图可能过时

子图画好之后（场景里元素最后一次修改的 `updated`），它负责的代码（它的所有路径 + 父节点自己的路径）又被任何会话写过，就标「可能过时」：

- 父节点的进入标记上一个提示色小点，悬停说明有几次改动；
- 子画布的面包屑栏里、当前子图名字旁边：一个提示色小点（`.nest-stale-dot`），不自己弹出；鼠标移上去（或键盘聚焦）才展开「可能过时：子图画好之后改过 N 个文件 · 让 AI 更新 · 已核对」。你自己点进来和镜头带着进来都只有这个小点。**让 AI 更新**把改过的文件列给 agent，只改变了的部分；**已核对**记下核对时间（`workspace.json` 里该画布条目的 `reviewedAt`），之前的改动不再算。
- AI 更新子图后元素的 `updated` 变新，标记自然消失。

这只看会话日志里的写入（和进度指针同一份数据）；终端外、编辑器里手改的代码不会触发。

## 7. 删除与生命周期（沿用现有规则，不定新语义）

- 子图就是普通画布：关闭 ≠ 删除，「所有画布」里找得回。
- **父节点被删**：子画布不动，只是没人指着它了（在「所有画布」里回到顶层）；页面底部提示「……里打开子图的节点没了：子图仍在所有画布里，只是断开了链接（⌘Z 可恢复）」，带「打开子图」。
- **删除父画布**：确认文案写明「它下面的 N 张子图不删，只断开链接，留在列表里」；撤销删除时链接回来（链接本来就在父画布里）。
- 删除子画布：父节点上的 `childCanvas` 指向不存在的 id，标记不显示；撤销删除后标记回来。

## 8. 分享：访客逐级进入

分享一块画布时，访客可以进它下面的所有子图（`nested.reachable`：从被分享的画布往下），其他画布一律 403：

- `GET /api/guest/state?canvas=<id>`：id 必须在可达集合里，返回那一层的画布、评论、`path`（从被分享的那一层开始，访客回不到更上层）、`canvases`（每张可达画布的名字和它及下层的未解决评论数）。
- `POST /api/guest/comments` 带 `canvasId`，同样检查；评论写进那张子画布的线程文件。
- 下发的元素仍去掉 `customData`，只给「指向可达子图」的节点留一个 `{childCanvas}`；代码路径等照旧不出本机。父节点被断开后，那张子图立刻不可达。
- SSE 推送覆盖所有可达画布（事件带 `canvasId`），进入标记上的评论数随访客和作者的新评论刷新。

## 9. 取舍

- **原地切换而不是开新 tab**：层级是同一个东西的不同粒度，像文件夹里点进点出；想并排看两层，从「所有画布」把另一层拖到别的分组即可。
- **只存父→子一个方向**：不在子画布里记「我的父亲是谁」，就不会有两处说法不一致；代价是找父亲要扫所有画布（画布数量小，页面里本来就有全部场景）。
- **缩放进出用图片当过渡，不同时挂两块画布**：缩略图是子图的 SVG 导出，不带图片元素（`files` 不导出），也不是可交互的；好处是父画布上一直只有一个编辑器，切换之后才是真画布。
- **限制**：触摸屏上的双指捏合（不经过 ctrl + 滚轮的那种）不识别；子图镜头要小于 10% 或父画布要大于 3000% 时会被夹住，那一下不是严丝合缝；新画布挂载的那一帧里来的一下滚轮会丢；面包屑栏和 Excalidraw 的工具条比画面晚几帧出现。
- **过时用时间戳推断**：不给每个节点记「画的时候代码的版本」（要算哈希、要存），只比较「写入时间」和「元素最后修改时间」。会有误报（改的是注释），也会漏报（手改代码），所以只提示，不自动改。
