# 图要读得懂：排版、测量与连线

用户原话：「要考虑到线和线之间的链接，不只是直接生成图，从宏观到微观，最重要的是线尽可能不要交叉」。agent 以前是按坐标一个个摆节点、画直线，几十条线穿过别的节点和线。现在有三样东西，各自只在一处实现：

| | 做什么 | 在哪 |
|---|---|---|
| **量** | `agora canvas lint`，也附在每次 `apply` 的返回里：线与线交叉（哪几对、在哪）、线穿过不相干的节点、节点重叠或间距不足 40 px、线的标签被遮挡、节点文字比框宽（会溢出）、同一节点同一处叠了几条线、线重合、线总长和拐点 | `server/canvas/graph_lint.py` |
| **排** | `apply` 的 ops 末尾写 `{"op": "layout"}`：只排这一批新画的节点和线；已有的节点当固定约束，新的绕着放。`agora canvas layout --nodes … / --all` 才会动已有节点，而且默认只说会动哪些 | `graph_layout.py`（层与坐标）、`graph_route.py`（锚点、走线、跳线）、`graph_ops.py`（把 `layout` 展开成普通 ops）、`graph_hub.py`（挂到 `apply` / `lint` / `layout` 上） |
| **连** | 线的锚点沿边均匀分开；会穿节点或和别的线交叉的线走折线；不可避免的交叉画小跳线；4 条以上的扇入扇出可以用一个实心小圆点汇合（`"bus": true`） | 同上；页面里画出来靠 `web/src/canvas/scene.ts` 的 `buildArrow`（`path`、`plain`）和 `buildJunction` |

## 1. 共用一份实现，页面和服务端后备执行者都不含第二份

布局和测量是**纯 Python 函数**（输入输出都是 `agora canvas read` 那种场景 dict：`nodes` / `arrows` / `junctions`），不依赖页面、文件或网络：

- **页面执行时**：服务端在把 ops 交给页面**之前**跑布局，`layout` op 被展开成带坐标的 `add_shape`、带 `path` 的 `add_arrow` 和（要汇合点时）`add_junction`。页面的 `applyPlan` 只执行普通 op，没有排版算法，也不需要知道有 `layout`。
- **服务端后备执行者**（`fallback.py`，BR2）：同一批展开后的 ops 交给它，它认得的做，认不得的（`add_shape`、`add_arrow` 要画元素）照旧报「这条要打开页面才能做」，整批不执行。它在 `apply` 之后照样能量：`lint` 读文件里的画布，结果里同样带 `lint`。
- **测量**：`apply` 成功后服务端再读一次画布（有页面读页面的实时场景，否则读文件），交给 `graph_lint.lint`。页面里没有第二份测量代码。

理由：算法只有一份，两个执行者不可能算出不同的答案；页面里不必带一套 Python 已有的图算法；后备执行者以后要支持更多 op 时，直接用同一个函数。

场景里多了两样东西（`model_view.py`，前端 `toModelView` 同构，几何在 `web/src/canvas/lines.ts`）：

- `arrows[].path`：这条线的绝对坐标点；**只有不是页面默认画的那条直线时才有**（默认直线：两端在两个节点边缘外 6 px，朝对方中心）。所以没排过版的老图读出来和以前一样。
- `junctions`：汇合点（`customData.junction`，10×10 的实心小圆）。它不算节点：`nodes` 里没有，`lint` 不数它，线可以画到它上面。

## 2. 布局算法（`graph_layout.py`）

1. **分层**：打破环（DFS 反转回边），最长路径分层，纯源点贴着第一个目标放。含固定节点的层取它们真实的高度，其余层从它往上下叠。层间距 88 px，同层间距 56 px。
2. **层内顺序**：跨多层的线在每层留一个占位（让别的节点不占那条线的路）。顺序用重心法上下来回扫、相邻交换，从 24 个确定的起点各跑一遍，取（层间交叉数，线长）最小的。固定节点的位置就是它自己的位置，新节点排在它们之间和周围。
3. **尺寸**：新画的节点没写 `width` / `height` 时，按标签文字定大小（宽 160–360 px，多行加高），不会再出现文字溢出框外；agent 自己写了尺寸的不改。
4. **坐标**：每层按邻居的重心取理想位置，再按宽度和间距用保序回归（PAV）推开；固定节点是不动的钉子。仍然重叠的新节点向右挪到有 40 px 空气为止（兜底）。
5. **不相连的新图**排在已有内容的下方（间距 120 px），互相不相连的几块并排。
6. **同一个输入得到同一个结果**（没有随机数，种子固定）。走线的搜索最多花 8 秒（`graph_route.BUDGET_S`），超时后还没干净的线保留手边最好的走法；服务端在线程里算，不占事件循环。

已有节点不动是硬约束：`layout` 的结果只包含新节点（或 `reflow` 里点名的节点）的坐标，`tests/test_graph_layout.py` 锁住。

## 3. 线的走法（`graph_route.py`）

- **锚点**：同一节点同一侧的多条线，按对方来的方向排序后沿边均匀分开（15%–85% 之间）；那一侧已有别人的线时，新锚点避开它 14 px。
- **走线**：直线优先。直线穿节点或和别的线交叉时，依次试：经过布局为这条线留的占位的折线、在层间通道里的正交折线（几个高度）、最后在以节点外 16 px 为障碍的网格上做 A\* 搜索（拐点、交叉、重合都有代价；斜线的拐点比直角的更贵，所以长线优先走横竖）。选总代价最低的。两轮：第二轮按第一轮线实际来的方向重排同一侧锚点的顺序。
- **跳线**：还剩的交叉，新线在老线上方画一个小凸起（宽 20、高 10 的三段折线）；两条新线交叉时较平的那条跳。`graph_lint` 认得这种凸起，交叉点落在凸起上算「跳线」，不算交叉。
- **汇合点（`bus`）**：一个节点发出（或汇入）≥ 4 条这批新线时，画成一条干线接到一个小圆点，再从圆点分出去；干线是没有箭头的线，分支带箭头。圆点放在这个节点所在层和下一层之间的空隙里，横线不会穿节点。汇合点不参与分层，所以不改变节点的排布。

**Excalidraw 的肘形箭头**：0.18.1 支持（`elbowed: true`），但走线由编辑器自己算；我们的折线是自己算的（避开节点、错开锚点、带跳线），所以画成普通的多点箭头（`elbowed: false`）。用户之后拖动它连着的节点时，端点跟着走，中间的拐点留在原地（临时项目里用真页面实测过：拖 M4 下移 20 px，线的最后一点跟着到 M4，中间点没动）。页面执行 `layout` 展开出的 op 时，带 `path` 的线在同一批里不会被「节点几何变了就重画成直线」的规则改回去；后面的 `move` / `resize` 才会把它们放回直线。

## 4. 接口

```bash
agora canvas lint [--canvas id]                       # 一句话 + 明细；没有服务也能用（读文件）
agora canvas apply --base r-… <<'JSON'                # 新画的一批，最后一条写 layout
[{"op":"add_shape","ref":"a","shape":"rectangle","text":"网关","x":0,"y":0}, …, {"op":"layout"}]
JSON
agora canvas layout --nodes a,b,c | --all [--apply]   # 排已有的节点：默认只说会动哪些和前后对比
```

- `layout` 必须是最后一条，且只能有一条；`{"op": "layout", "bus": true}` 打开汇合点；`{"op": "layout", "reflow": ["id", …]}` 把点名的已有节点也一起重排（`plan_reflow` 先给预览，再由 `--apply` 执行）。展开后可能超过 20 条 op，这没关系：20 条是 agent 单次写的上限。
- 展开后多出的三种 op：`add_arrow` 的 `path` / `plain`、`add_junction`、`route`（给已有的线改走法，`path: null` = 回到默认直线）。agent 不用自己写这些。`agora canvas schema ops` 会列出 `layout`，不会列这三个内部字段之外的东西。
- 服务端路由：`POST /api/agent/canvas/lint`、`POST /api/agent/canvas/layout`（`nodes` / `everything` / `execute`）。

## 5. 限制

- `insert_library_item`（素材库组件）不参与排版：它们按自己的 `near` / `at` 摆。
- 只有「上游在上、下游在下」一个方向。
- 汇合点只用于这一批新画的线；已有的线不会被改成汇合点。
- `reflow` 里的已有线，页面上端点之外的拐点会被重画；未列入的线不动。
