# 工作台焦点：屏幕上只留回答当前问题的东西

设计稿 `workbench-focus/index.html`（状态 a–j，「之前」模式和「取舍」抽屉里有逐项去留表）。原来的屏幕上同时有 31 样东西，其中 5 样都在说「agent 在这 / 做过什么」，紫色出现在十几处。本轮（v1）实现 P0–P2；P3–P5 见 [工位视图](workstation.md) §9。

## 1. 顶栏

- 只剩：品牌、项目名、分享（安静样式）、⋯。
- ⋯（`app/ViewMenu.tsx`）：布局（单窗 / 左右 / 上下 / 平铺，另有「恢复默认布局」：画布在左、会话在右两栏）、主题（跟随系统 / 浅色 / 深色）、工位视图（小人）、显示已解决的评论、画布操作提示、快捷键与帮助（`?` 也能打开）。开关记在本浏览器（`app/prefs.ts`，`agora.view`）。
- 顶栏的「新建会话」「新建画布」去掉：新建只在两个 tab 栏的「+」。画布 tab 栏的「+」是一个小菜单：新建画布、从示例新建画布、打开画布（N）——原来的「所有画布」列表从这里打开（回收站、历史也在里面）。会话 tab 栏的「+」直接新建会话。

## 2. 会话面板

- 头部一行：`🔒 模型 · ▪ 画在：<画布名>`，右边三个图标：轨迹（开关）、在终端打开、⋯（轮数、耗时、花费、tokens、会话 id，以及在 Kitty 中打开、复制打开命令、终端开着时的关闭终端）。名字已经在 tab 上。「画在」悬停写「这个会话改图、画小人、接评论时用的图」；下拉只列顶层画布（子图属于同一棵树，不单列，`session/canvasChoices.ts`），只有一张顶层画布时不出下拉，只显示文字。
- 终端只有一种说法：有可写的终端窗口连着（或你接管了）时，输入框上方是「终端窗口开着 · 你的话在排队」加「现在送出」「接管」（`InputRight`，没有排队的话时「现在送出」灰）；没有窗口连着时面板里不出现任何终端相关的东西。「在终端打开」点了以后窗口开起来就是上面那一条，不再另写「已在 Kitty 中打开」；只有没打开成功或复制了命令才有一句提示，几秒后消失。
- 每轮：「第 7 轮 · 15:21」、用户的话、一行过程（展开看工具调用）、每次改画布一行「改了画布 · 新建子图「API 服务」…」（悬停出撤销 / 在画布中高亮，悬停时画布上高亮这次动过的元素，▸ 展开清单）、答复。
- 在干活时：一行「正在写 server/users.py · 3.5 秒」（等你时是暖色「在等你回复」），输入框提示「新消息会排在这一轮之后」，旁边「停止」。
- 输入框下没有运行方式的开关：在面板里还是通过终端窗口运行由 Agora 自动决定（见 [Claude 无头双工](../../docs/claude-headless-duplex.md)）；原来重复的「画布 · …」标签去掉。
- 回放时自动切到轨迹，之后发生的变灰，回到实时后切回对话。

## 3. 画布

- Dock：浏览 / 评论 + 「评论 N」（打开评论列表）。「评论选区」并进评论模式：先选中元素再按 C（或点评论），评论这组选区。「清空画布」挪进 Excalidraw 的 ☰ 菜单（仍是可撤销的一步）。
- Excalidraw 的提示行只在空画布上显示，或 ⋯ 里打开「画布操作提示」。
- 空画布：点阵、一句话「这张图还是空的：让 agent 画出这个项目的架构（会话里的「画出这个项目的架构」），或者自己动手画」、一个「看一个示例」（打开示例图为另一张画布，不覆盖这张）。三步说明去掉了：主按钮只有会话选择器上方那一个。
- 选 agent：三张卡片（Pi 快，适合边画边聊；Claude Code 擅长大改动，能派子代理；Codex 适合按清单写代码和测试），各自带默认模型；模型和强度还能改。「也可以直接在右边画，之后再开会话。」

## 4. 评论

- **默认**：画布上只钉进行中的评论；Dock 的数字只数进行中的。
- **显示已解决的评论**（⋯ 或评论列表头的开关，本浏览器记住，分享访客同样默认关、同样能开）：已解决的钉很安静——石墨空心描边、✓ 加小号编号、约 60% 不透明、从不用紫，永远在进行中的钉下面。悬停出第一行和「已解决 · 谁 · 何时」；点开在评论列表的「已解决」里，带「重新打开」。回复已解决的评论会重新打开它。
- **锚点失效**（元素被删了）：永远不画在画布上，开关也不管。评论列表底部「锚点已失效」分组，进行中的在前（暖色点），可以「重新钉到…」（再点一个元素）或删除。原来虚线灯泡的徽章去掉了。
- 评论列表头：进行中 N · 已解决 M，以及同一个开关。
- **评论列表是悬浮面板**（`comments/CommentsDrawer.tsx`、`drawerFloat.css`，外壳和会话面板共用：`app/floatShell.ts`，见 workstation.md §15「悬浮会话面板」）：浮在画布上，不占布局，打开、关闭、收起时画布大小不变；默认靠右上，在画布自己的顶行（工具栏、素材库、「跟看 …」那一行）之下、底部控件（缩放、浏览 / 评论、帮助、紧凑布局的底栏）之上，宽度 360–520（拖左边缘调，默认 420）、窄画布上跟着缩；拖头部可以挪位置（不会拖出画布，Alt+方向键也行）；头部的「−」（或聚焦头部按 Esc）收成右上的一个小圆按钮（写着进行中的条数），点它展开，✕ 或 Dock 的「评论 N」是关闭（什么都不留，再打开就是完整的面板）。位置、宽度和「收起」存在本浏览器（`agora.float.comments`，每个浏览者自己的，访客也一样；旧的 `agora.commentsPanel` 里的位置照旧读进来）；悬浮的会话面板展开时，这个列表收成小圆按钮，反之亦然（一次只展开一个）；收起着重载页面，小按钮还在。内容照旧：进行中 / 已解决、「在画布上显示已解决」、列表、「锚点已失效」。验收规则 P6：1000×800 和 1440×900 下它与 Excalidraw 自带控件、我们的 Dock 的包围盒不相交。
- 子图入口上的数字只数进行中的。
- 纯函数和测试：`comments/visibility.ts`、`comments/visibility.test.ts`（钉子过滤、失效分组、回复重开、重新钉）。
