# 工位视图：看每个 agent 在图上干活，并能回放

参考 Loom Studio（loom-studio-sep-2026.moldandyeast.com：把工序编译成时间线，由程序化小人走路、拿取、在机器旁工作，下方按人分泳道显示行走 / 工作 / 阻塞 / 等待，可拖动回放）。Agora 里的对应物：每个会话是一个小人，在架构图上走到它正在读写的节点旁「工作」，下方一条可展开的时间线按会话分泳道，拖动它就回放小人和进度指针。

它是画布的一个**可选视图**（画布右上角「工位视图」开关，按画布记在本浏览器 `localStorage` 的 `agora.workstation`），不改变原有指针。

实现：`web/src/workstation/timeline.ts`（纯函数：日志 → 泳道片段、压缩空闲的时间轴、某一时刻小人在哪做什么），`clock.ts`（实时 / 回放时钟），`Figure.tsx`（小人），`Workstation.tsx`（开关、小人层、时间线面板）。

## 1. 数据：只从会话日志来

泳道由每个会话的转录条目（`server/canvas/transcript.py` 从 Claude / Pi / Codex 原生日志读出的 `tool`、`user`、`end` 等）折成：

| 片段 | 来自 | 颜色 |
|---|---|---|
| 读 | 读文件、搜索、网页读取类工具（`Read`、`grep`、`read_file`、`web_fetch`…） | 浅紫 `--accent-soft` |
| 写 | 编辑 / 写入工具（驱动进度指针的那些） | 紫 `--accent-fill` |
| 执行命令 | shell / exec 类工具、其他工具、子 agent | 石墨 `--series-3` |
| 思考 | 一轮之内两次工具调用之间（模型在生成） | 浅底描边 |
| 等待用户 | agent 向人提问的工具（`AskUserQuestion`、`request_user_input`）进行中 | 提示色斜纹 |
| 空闲 | 两轮之间（不画片段，只有基线） | — |

- 并行调用（一步里同时读三个文件）按先后排开：一个小人一次只做一件事。
- 太短的调用至少画 0.6 秒，太短的思考不画。
- 读的文件路径取工具输入里的路径（Claude 的 `file_path`、Pi 的 `path`），换成项目相对路径；Codex 用 shell `cat` 读文件，识别不出路径，算「执行命令」。
- **时间轴**：所有泳道共用；没人干活超过 20 秒的空档压成 3 秒宽，并画一条虚线（悬停显示空了多久）。实时模式轴的右端是「现在」。

## 2. 小人

- **在哪**：它最近一次读或写的文件映射到哪个节点（和指针同一套有效路径，含子图汇总），就站在那个节点左下方；映射不到的文件在右下角「图外」工位；还没读写过的在右下角的起点。同一处的小人并排。
- **走路**：在下一次读 / 写开始前 0.9 秒出发，调用开始时刚好到达（缓动插值）。
- **姿态**：走路（摆腿摆臂）、写（抱着紫屏小电脑，手在敲）、执行命令（石墨屏上 `>_` 闪烁）、读（捧着一页纸）、思考（手托下巴，头顶三个点依次亮）、等待用户（举手 + 问号气泡）、空闲（站着、变淡、不显示说明）。头是 agent 的头像。脚下一个小胶囊写着在做什么（「写 service.py」）。
- **清晰**：全是矢量（SVG 线条 + 头像组件），位置按设备像素对齐（`Math.round(x·dpr)/dpr`），Codex 头像按尺寸 × dpr 选 64/128px 位图。
- **不遮界面**：小人层和指针层一样在 Excalidraw 界面之下，并按面板裁剪（[多 Agent](multi-agent.md) §2）。
- 点小人打开它的会话。

## 3. 确定性回放

- 小人的位置和姿态是 `figureAt(泳道, t)` 的纯函数；指针同样按 `t` 之前的写入计算。直接跳到某一刻和一路播放过去得到完全相同的画面（有测试）。
- 时钟（`clock.ts`）：实时，或回放位置 `{at, playing, speed, since}`；播放中的时刻永远是 `at + (现在 − since) × speed`，**从墙上时钟算，不按帧累加**。浏览器在后台标签页暂停 `requestAnimationFrame` 时逻辑不会卡住或变慢，回到前台第一帧就是正确的时刻；另有 1 秒一次的定时器兜底。帧只负责重绘。
- **时间线操作**：拖动任意位置回放（小人和所有指针一起移到那一刻）；点一个片段跳到那次调用的中间时刻，同时打开该会话的轨迹、定位到那一轮，并在画布上短暂高亮对应节点；播放 / 暂停，速度 1× / 4× / 16× / 60×；「回到实时」；时间线获得焦点后 ← → 步进 5 秒（Shift 60 秒），Esc 回到实时。
- 泳道名字点一下打开那个会话；时间线可以收起成一行。

## 4. 克制与可达性

- 只用设计规范里的一种紫、石墨中性色和提示色；不做渐变光晕（「等待用户」的斜纹是图案，不是渐变）。
- `prefers-reduced-motion`：不走路（直接到位）、四肢不动、思考的点不闪，时钟 1 秒一跳。
- 回放时间线是 `role="slider"`，有 `aria-valuetext`；小人按钮带「Codex：写 service.py」这样的名称。

## 5. 取舍

- **平面而不是轴测**：Loom 的 30° 轴测好看，但 Agora 的画布是用户自己画的平面架构图，把它斜过来会破坏图本身；小人站在节点旁边已经能表达「在哪干活」。
- **读也移动小人**：进度指针只看写（「改到哪了」），工位视图也看读（「在看哪」），否则小人大部分时间站着不动。两者分开，指针的规则不变。
- **不加专门的「工位」数据**：全部从现有日志推出来，不写新文件；代价是只能显示日志里有的东西（例如 Agora 自己的排队、终端里的打字都看不到）。
