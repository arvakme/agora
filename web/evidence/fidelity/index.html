差异、性能、动效

改了什么

  • 气泡：原型的写法和样式（动词图标、完整路径、28px 高、lift-2 阴影、子代理小一号、回执胶囊、验收通过、空闲气泡）。
  • 气泡摆放：先试原型自己的位置（脚左 20px、头线上 34px，尾巴指着自己；同一节点几个人时往上叠）；不行只在自己头顶左右滑、抬一行（细竖线）或贴在头旁；再不行收成头顶的小签（写/读/跑/想/等你/走/?），不再跑到节点下面。不压节点、文字、图标、箭头标签、别的小人；两个气泡永不重叠。
  • 工位：原型 dockPoint（上沿左起 24px、每人 46px，可伸出两位），读节点/素材库图标整组连名字的范围，站着的小人不压别的文字和图标；上沿站不下换右侧、左侧、下方。图外托盘贴着图里最下面的节点（原型的位置），托盘和上面的小人不压东西。
  • 节点描边：写/等你/读（虚线）/其他在干活/冲突/悬停/选中，按原型；空闲小人 62% 不透明；牵绳弧度按原型。
  • 时间线：默认就是原型的时间线（标题、状态胶囊、播放/上一步/下一步、1×2×4×、提示、图例、展开、✕；30px 泳道、带字片段、走路细条、派出/交回竖线、子泳道回执带、冲突带、锯齿空闲段、播放头「● 现在」、回放遮罩、悬停卡片、详情卡）；展开有「在 API 服务」行、回执带文字、详情栏和图例行。
  • 时间线变高时画布保持上沿不动（原来会按居中规则把图往上推半个高度）。

剩下的差异和原因

  • 图形本身是 Excalidraw 画的（手绘线、字体），原型节点里的「⌘ server/**」行是原型自己的模拟，Agora 节点里没有这一行。
  • 页面外壳：Agora 的顶栏、工具条、底部缩放和「浏览/评论」栏在画布里，原型没有；对照图按同一个世界矩形裁，Agora 画布下沿被这些压住一截。
  • 同一节点几个人：原型按会话固定工位号（会留空位，t=24 Pi 和 Codex 之间空一位），这里按树序紧排——真实会话数不定，固定号会把人推出节点。
  • 原型的气泡会互相压住（t=5、24、30、36 都有），这里永不重叠：挤不下的收成头顶小签（t=30 worker-3「?」、子代理「走」），子代理最后才收成 +N。
  • 小人避开文字和图标：原型 t=24 Claude Code 站在「子服务」标签上，这里挪到上沿右边空处。
  • 时间线：时间轴比「现在」多留跨度的 2%（0.5–6 秒），走到头才重排（性能：两次重排之间已结束的片段不动），所以「现在」离右端差几像素；✕ 收成 34px 细条而不是关掉工位视图（开关在 ⋯ 菜单）；Agora 画布更宽，每秒像素更多，刻度 2 秒一格。
  • 结构 4 Hz 重建，气泡和泳道名里的秒数和原型最多差 0.25 秒；Codex 在 t=24 这类恰好在边界上的时刻可能差一个动作。
  • 真实数据：写文件的 diff 不在运行树里，详情卡显示命令、问题、派出回执链，不显示 diff。

性能（18 个 agent × 500 元素，叠层开销 = 开 − 无叠层）

  • 改之后两次：空闲 3.73 / 3.89 ms，平移 3.32 / 3.25 ms（预算 4 ms）；60 fps。perf/bench-fidelity.json。
  • 同一台机器上 5c3b66b：空闲 3.02，平移 2.85 ms。多出来的是默认展开的泳道（4 Hz 重建）。
  • 做法：片段用 left 定位（每段一个 transform 会各成绘制块/合成层，layerize 每帧付钱）；泳道区自成合成层；已结束片段和泳道名按内容记忆；写冲突按文件分组；气泡量尺寸不再来回切换属性。

动效（motion-capture，?mock=runs 整段脚本）

  • 浅色、深色：走路 / 换姿态 / 气泡进出 / 交接退场 0 掉帧、0 次 >2px 跳变（最大 1.2px）。
  • 拖动回放：浅色 1 帧、深色 1 帧掉帧（拖动开始时一帧 33 ms；追踪里是一次没有子事件的 BeginMainFrame，时有时无，改之前的减少动效那次也有 1 帧）。
  • 减少动效：小人和气泡 0 次跳变；播放头按设计小步前进，被计成「跳变」（改之前同样如此）。
  • 气泡锚在小人脚上；气泡换位置的滑动按加速度上限定时长（起停都不超过约 2000 px/s²），走路的小人不再让别的气泡躲来躲去；帧循环用 rAF 自己的时间戳。
