# Agora 宣传片 · treatment

按 huashu-motion 的流程写（director §5、rhythm §7），节奏纪律借 cinetic（一个贯穿物、文案碎片化、一张拍子网格同时驱动画面和声音、渲染后看帧审片）。

## 读产品

- **是什么**：每个项目自带的本地控制面。你自己装、自己登录的 coding agent（Claude Code、Codex、Pi，以及 Grok、Cursor、Devin）在项目的 Excalidraw 架构图上干活；agent 是图上的小人，读写哪块代码就走到哪个节点。
- **一件事**：agent 改代码时，你能在架构图上看见它在哪、画了什么。
- **性格**：精确 +1、偏有活力 +1、亲和 0、技术 +2、新 +2——「手绘感的开发工具，克制、会动」。
- **真材料**：`/mnt/project-files/agora-motion-video/` 的实录（逐站揭示、缩放进子图、多 agent 跳和滑行），`docs/media/` 的产品截图，README 横幅，README 示意图。屏上每句话都能对上 README 或 `web/docs/`。
- **投放**：README 链接、X / 小红书（16:9 主版 + 9:16），先静音也能看懂。
- **口播**：没有。只有音乐和音效。

## 三个方向（没有用户实时挑，选 A，理由写在下面）

- **A · Fit（选中）**：README 示意图的纸面（点阵、角标、细线）当片头和过场，中段放真实录屏；贯穿物是**小人**。混合路线：一条主线 + 中段一串一拍一切的蒙太奇。
- B · Amplify：整片一个连续镜头，从横幅的星座架构图一路推进到录屏里，再拉回星空。最漂亮，但录屏素材分辨率撑不住大推镜。
- C · Unexpected：古希腊广场（agora）的剪影剧场，小人是在广场上辩论的人。离产品太远。

## 贯穿物

小人：片头它走上一条线、线变成节点；录屏里是真的工位小人；示意图里站在画布节点上；安装那段站在终端窗口顶上敲命令；结尾落回横幅里站在星座节点上的小人。

## 节奏单（120 BPM，一拍 0.5 s，一小节 2 s；场景标签都在拍子上，配乐 0 % 弯曲）

| 段 | 小节 | 时间 | 能量 | 画面 | 文案（碎片） | 声音 |
|---|---|---|---|---|---|---|
| hook | 1–2 | 0–4 | 6 | 纸面，小人走上一条线；打字「说一句话」；线画成节点，再长出两个节点和箭头；中间节点放大成窗口 | 说一句话 → agent 把架构画出来 | 底鼓和踩镲从第一拍起，motif 第一次出现；打字声；画线声；4.0 whoosh 落在切点 |

| build / stop | 8 | 14–16 | 8→1 | 纸面大字「图里还有图」砸下；15.0 停住，节点里套着一个小节点，往镜头吸 | 图里还有图 | 军鼓滚奏 → 半小节静音只剩上升音和反向吸气 |
| drop | 9–10 | 16–20 | 9 | 实录：滚轮放大节点，子图在节点里浮现并切进去；再飞进下一层 | 放大节点，就进到子图 | 全编制，crash + impact + subdrop |
| burst | 11–12 | 20–24 | 10 | 八个镜头一拍一切：素材库、几个 agent、进度指针、轨迹、终端、分享、访客页、沿箭头滑行；标签钉在同一位置换字 | 每拍一个标签 | 每个切点一个 hit，音高逐个升；12 小节末尾通鼓过门 |

| install | 15–16 | 28–32 | 7 | 深色终端窗口，小人站在窗口顶上；敲出安装命令和 `agora` | 命令本身就是文案 | 打字声，回车声；16 小节末军鼓滚奏 |
| logo | 17–20 | 32–40 | 8→3 | 横幅全屏缓慢横移；Agora 字标、副标、仓库地址逐拍落下；最后一秒淡出 | Agora · 一个项目一个 Agora · github.com/arvakme/agora | hit；33.0 结尾 sting；motif 作为声音标志；19 小节一下收住，余音到 40 s |

检查：3 s 内有起拍（第一拍就有鼓和动作）；burst 在 50–60 %（20–24 s），8 刀一拍一切；hero（进子图）在全片最强的拍点（drop）；每个段落边界至少换两样（景别、底色、速度、音乐织体）；没有超过两小节什么都不发生的地方。
