# Answering a comment

A message that starts with `画布评论 #N（锚点：…）` is a request about that spot of the
diagram; the anchor ids are given.

1. `agora canvas read` and find the anchor ids. Change the diagram only if the comment asks
   for it ([canvas-ops.md](canvas-ops.md)); a question needs no edit.
2. Answer in the comment's language in one or two sentences. That final answer is posted back
   into the thread, so say what you did or found, not what you plan to do.
